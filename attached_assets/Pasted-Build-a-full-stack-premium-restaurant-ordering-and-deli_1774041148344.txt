Build a full-stack premium restaurant ordering and delivery platform for a restaurant brand called Seagull.

This app must be designed to feel like a high-end hospitality product, not a simple delivery clone. The final result should be elegant, production-ready, and suitable for a serious client pitch in Egypt.

DESIGN DIRECTION
- Use the attached logo as the inspiration for the branding.
- Build the UI around a luxurious ocean-blue, deep navy, charcoal, white, and silver-gray palette.
- The interface should look modern, premium, trustworthy, and polished.
- Use smooth transitions, refined spacing, elegant cards, premium buttons, and high-end typography.
- Keep the experience mobile-first, but make sure the system also supports tablet and desktop views cleanly.

BUILD THE FULL PRODUCT
Create the following parts:
1) Customer app
2) Rider tracking and delivery workflow
3) Restaurant management dashboard
4) Admin dashboard
5) Payment integration layer for Egypt
6) Notification and status event system
7) Analytics and reporting layer
